# EchoNeuroSlop — Обзор проекта

## Концепция

**EchoNeuroSlop** — прототип игры от первого лица, где игрок ориентируется исключительно с помощью эхолокации. Мир полностью погружён во тьму: в сцене нет источников света. Любой звук — шаги, крик, падение предмета — порождает звуковую волну, которая на долю секунды обрисовывает контуры окружающей геометрии.

## USP (Unique Selling Point)

Единственный способ «увидеть» мир — издать звук. Тишина = полная слепота. Это создаёт напряжение: чтобы ориентироваться, нужно шуметь, но шум привлекает внимание.

## Целевые ощущения

- **Тревога** — игрок не знает, что скрывается в темноте
- **Тактильность** — каждый звук ощущается как «прикосновение к миру»
- **Ритм** — чередование тишины и вспышек эхо-визуализации

## Технологический стек

| Компонент | Технология |

| Движок | Unity 6 (6000.3.0f1) |
| Рендер-пайплайн | URP 17.3.0 |
| Ввод | New Input System 1.16.0 |
| Шейдеры | HLSL (URP Shader Library) |
| Навигация | AI Navigation 2.0.9 |
| Платформа | Windows (PC) |

## Структура проекта

```
Assets/
├── Scripts/          # C# скрипты
│   ├── Core/         # EchoManager
│   ├── Player/       # FPS контроллер, ввод
│   ├── Echo/         # Логика эхо-источников
│   └── Audio/        # Интеграция звука с эхо-системой
├── Shaders/          # HLSL шейдеры (при переходе на Подход C)
├── Materials/        # Материалы
├── Prefabs/          # Префабы
├── Scenes/           # Сцены
├── Audio/            # Звуковые файлы
└── Settings/         # URP Asset, Renderer, Volume Profile
Docs/                 # Проектная документация
```
