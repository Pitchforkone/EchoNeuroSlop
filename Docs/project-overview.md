# EchoNeuroSlop — Обзор проекта

## Концепция

**EchoNeuroSlop** — кооперативный хоррор от первого лица на 2 игроков. Мир погружён в абсолютную темноту: в сцене нет источников света. Единственный способ «увидеть» окружение — звук. Любой звук — голос в микрофон, шаги, крик, падение предмета — порождает расширяющуюся звуковую волну, которая обрисовывает контуры геометрии.

Игроки общаются через микрофон. Их голос создаёт эхо-волны, дающие видимость, но привлекающие врага. На уровне обитает сущность, которая охотится на звук.

## USP (Unique Selling Point)

**Кооперативная эхолокация**: два игрока должны координироваться голосом, чтобы ориентироваться в полной темноте, при том что каждое произнесённое слово создаёт волну видимости — и приглашение для врага.

Тишина = слепота + безопасность. Звук = видимость + опасность.

## Целевые ощущения

- **Тревога** — нельзя молчать вечно, но каждое слово рискованно
- **Доверие** — два игрока зависят друг от друга в темноте
- **Дилемма** — говорить, чтобы видеть, или молчать, чтобы выжить
- **Сотрудничество** — один отвлекает, другой продвигается

## Технологический стек

| Компонент | Технология |
|---|---|
| Движок | Unity 6 (6000.3.0f1) |
| Рендер-пайплайн | URP 17.3.0 |
| Мультиплеер | Netcode for GameObjects (NGO) |
| Ввод | New Input System 1.16.0 |
| Голос → эхо | UnityEngine.Microphone (детекция громкости) |
| Голосовой чат | Vivox / внешний (Discord) на этапе прототипа |
| Шейдеры | HLSL (URP Shader Library) |
| Навигация | AI Navigation 2.0.9 |
| Платформа | Windows (PC) |

## Структура проекта

```
Assets/
├── Scripts/
│   ├── Core/         # EchoManager, GameManager
│   ├── Player/       # FPS контроллер, ввод, микрофон
│   ├── Echo/         # EchoSource, EchoPreset
│   ├── Network/      # Сетевая инициализация, лобби
│   ├── Enemy/        # AI врага
│   └── Audio/        # Интеграция звука с эхо-системой

├── Materials/
├── Prefabs/
├── Scenes/
├── Audio/
└── Settings/         # URP Asset, Renderer, Volume Profile
Docs/                 # Проектная документация
```
