# План прототипирования

## Фазы разработки

Прототип разбит на 5 фаз. Каждая фаза завершается **играбельным билдом**.

Задачи разделены:
- 💻 **Код** — реализует Copilot (C#, шейдеры)
- 🎛️ **Инспектор** — настраивает разработчик вручную в Unity Editor
- 📦 **Пакеты** — установка через Package Manager

---

## Фаза 3: Голос → Эхо

**Цель:** говоришь в микрофон — создаёшь эхо-волну от своего персонажа.

### 💻 Код (Copilot)

- [ ] **3.1** `MicrophoneCapture.cs` (MonoBehaviour, локальный):
  - `Microphone.Start()` → `AudioClip.GetData()` → RMS каждые ~50мс
  - Callback при превышении порога громкости
  - Работает только на owner-клиенте
- [ ] **3.2** Интеграция с `PlayerEchoLocator`:
  - MicrophoneCapture → callback → `PlayerEchoLocator.OnVoiceDetected(intensity)`
  - → `SendEchoServerRpc(position, intensity)` → оба видят эхо
  - Маппинг громкости → радиус/интенсивность: тихий шёпот = 3м, нормальная речь = 10м, крик = 20м
- [ ] **3.3** `MicrophoneSettings.cs` (ScriptableObject) — порог, cooldown, маппинг громкости

### 🎛️ Инспектор (разработчик)

- [ ] **3.4** Добавить `MicrophoneCapture` на Player Prefab
- [ ] **3.5** Создать MicrophoneSettings ассет и настроить пороги
- [ ] **3.6** Протестировать: говорить в микрофон → должно появляться эхо

### Результат фазы
Игрок говорит → от его персонажа расходится эхо-волна. Громче говоришь = больше видно. Оба игрока видят эхо друг друга.

## Фаза 4: Враг + звуковая экосистема

**Цель:** враг охотится на звук, мир «живёт» своими звуками.

### 💻 Код (Copilot)

- [ ] **4.1** `EnemyAI.cs` (NetworkBehaviour, server-authoritative):
  - NavMeshAgent, запускается только на host (`if (!IsServer) return`)
  - Состояния: Patrol → Investigate → Chase → Search → Patrol
  - Слушает эхо-события от EchoManager: `OnSoundHeard(position, intensity)`
  - Сам генерирует эхо при движении (красное, ServerRpc → ClientRpc)
  - `NetworkTransform` для синхронизации позиции
- [ ] **4.2** `AmbientEchoSource.cs` (MonoBehaviour, не сетевой):
  - Циклический источник: капли, вентиляция
  - Одинаковый на обоих клиентах (детерминированный таймер)
- [ ] **4.3** `EchoAudioBridge.cs` — helper: воспроизвести звук + создать эхо синхронно

### 🎛️ Инспектор (разработчик)

- [ ] **4.4** Создать Enemy Prefab: NavMeshAgent + EnemyAI + NetworkObject + NetworkTransform
- [ ] **4.5** Назначить Enemy Prefab для спавна на host при старте
- [ ] **4.6** Запечь NavMesh (Window → AI → Navigation → Bake)
- [ ] **4.7** Расставить точки патруля врага
- [ ] **4.8** Расставить ambient-источники: капающая вода (голубой), вентиляция (серый)

- [ ] **4.10** Добавить звуковые файлы в Audio/

### Результат фазы
Враг патрулирует, слышит игроков, идёт на звук. Своё движение враг визуализирует красным эхо. Ambient-источники мерцают.

## Приоритеты

| Приоритет | Что | Почему |
|---|---|---|
| 🔴 P0 | Фаза 1 (сеть + контроллер) | Без сети нет кооператива |
| 🔴 P0 | Фаза 2 (сетевое эхо) | Core-механика |
| 🔴 P0 | Фаза 3 (голос → эхо) | USP — голос как источник видимости |
| 🟡 P1 | Фаза 4 (враг + ambient) | Создаёт хоррор и tension |
| 🟢 P2 | Фаза 5 (геймплей) | Полный цикл |
| 🟢 P2 | Фаза 2.5 (визуал) | Polish, когда геймплей подтверждён |

## Метрики успеха прототипа

1. ✅ Два игрока подключаются и **видят эхо друг друга**
2. ✅ Голос в микрофон **создаёт эхо-волну** пропорциональную громкости
3. ✅ Игроки чувствуют **дилемму** «говорить = видеть + опасность»
4. ✅ Враг **реагирует на звуки** и создаёт ощущение угрозы
5. ✅ Стабильные **60 FPS** с 2 игроками и 8+ эхо-источниками
6. ✅ Уровень **проходим** при кооперации двух игроков
